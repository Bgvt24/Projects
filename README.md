Mini City Planner

An interactive, grid-based layout designer built in Python using the Tkinter GUI toolkit. This desktop sandbox application allows users to build out local infrastructures, roads, and municipal zones instantly using simple point-and-click mouse controls. 

Features

Structural Blueprints: Drag-free, single-click deployment for common residential and public structures including houses, schools, and red-cross hospitals.
Dynamic Infrastructure Layering: Dedicated placement modes for complex horizontal, vertical, and diagonal traffic thoroughfares featuring authentic dual-layer lane styling.
Dynamic Radio-Selection: An intuitive, single-toggle radio control panel anchored at the workspace footer to quickly swap active tools.


Requirements & Installation

This app uses standard Python components and does not require third-party packages or additional system dependencies. 

1. Ensure you have Python installed on your system (Python 3.x recommended).
2. Clone this repository or copy the project script into a local file named planner.py.

 How to Use

1. Run the Python script directly from your terminal or command prompt.
2. Select your desired element from the options at the bottom of the interface window (e.g., *House*, *Horizontal Road*, etc.).
3. Left-click anywhere inside the light green sandbox layout area to instantly stamp down and position that element.
